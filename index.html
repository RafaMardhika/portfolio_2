Schedule AI: dari daftar tugas ke jadwal harian

Masalah: menyusun jadwal itu melelahkan. Solusinya, pengguna memasukkan tugas, jam kerja, dan istirahat, lalu model bahasa menyusun jadwalnya dan hasilnya disimpan agar bisa dibuka lagi.

  2. Prompt terstrukturdikirim ke Groq API
  3. Baca jawabandiubah jadi item jadwal
  4. Simpan dataSupabase, 4 tabel
  5. Riwayatlihat ulang dan centang item selesai
